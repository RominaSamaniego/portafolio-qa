# 🚀 Portafolio de QA Manual - Romina Samaniego

¡Hola! Soy Romina, Analista de Quality Assurance especializada en testing manual. Este repositorio contiene evidencia de mis proyectos, metodologías y habilidades aplicadas al ciclo de vida del testing de software (STLC).

## 📂 Proyectos Destacados

### 🛒 1. E-Commerce "Farmacia DRahorro"
Este es mi proyecto principal donde simulé un entorno de trabajo ágil para asegurar la calidad de un e-commerce farmacéutico.

**¿Qué técnicas y herramientas apliqué?**
- **Análisis de Requerimientos:** Creación y análisis de Historias de Usuario con sus respectivos Criterios de Aceptación.
- **Diseño Funcional:** Modelado a través de Diagramas de Flujo y Matrices CRUD.
- **Diseño de Pruebas (Caja Negra):** Aplicación de partición por Clases de Equivalencia y Tablas de Decisión.
- **Ejecución y Documentación:** Diseño de una Estrategia de Pruebas y más de 25 Casos de Prueba modulares (Login, Carrito, Búsqueda y Registro).
- **Gestión de Defectos:** Reporte de Bugs documentando severidad, prioridad y pasos para reproducir.
