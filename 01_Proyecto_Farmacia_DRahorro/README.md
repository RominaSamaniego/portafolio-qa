# 🛒 Proyecto QA: E-Commerce "Farmacia Dr. Ahorro"

## 📝 Descripción General

Este proyecto representa una prueba integral de calidad de software (QA) sobre el portal e-commerce de **Farmacia Dr. Ahorro**. El objetivo principal fue diseñar y ejecutar un plan de pruebas exhaustivo que garantizara la estabilidad del sistema, la integridad de los datos de los usuarios y la correcta navegación dentro de los procesos de compra y gestión de cuenta.

---

## 📂 Contenido del Proyecto

Navega a través de los directorios para revisar la documentación generada:

### 1️⃣ [01_Estrategia_y_Reportes](./01_Estrategia_y_Reportes/)
Contiene la **Estrategia de Pruebas** donde se definen los objetivos, el alcance, los ambientes de prueba, los criterios de entrada y salida, así como las plantillas de reporte de cierre.

### 2️⃣ [02_Requisitos_y_Analisis_Funcional](./02_Requisitos_y_Analisis_Funcional/)
Documentación de las **Historias de Usuario (US)** con sus correspondientes **Criterios de Aceptación**, y la **Matriz CRUD** utilizada para validar los permisos de datos (Creación, Lectura, Actualización, Eliminación).

### 3️⃣ [03_Tecnicas_de_Diseno_de_Pruebas](./03_Tecnicas_de_Diseno_de_Pruebas/)
Evidencia de la aplicación formal de técnicas de caja negra:
- **Tablas de Decisión** para lógica condicional compleja.
- **Clases de Equivalencia** para optimizar la cantidad de datos de prueba necesarios (Buscador, Carrito, Registro, Login).

### 4️⃣ [04_Casos_de_Prueba](./04_Casos_de_Prueba/)
La suite completa de **Casos de Prueba (Test Cases)** dividida por módulos:
- Autenticación e Iniciar Sesión
- Registro de Usuario
- Buscador de Productos
- Carrito de Compras & Checkout
- Sección de Contacto
- Suite global en Cascada (28 casos)

### 5️⃣ [05_Gestion_de_Defectos](./05_Gestion_de_Defectos/)
Matriz y reporte detallado de **Bugs (Defectos)** encontrados durante la ejecución, clasificados por ID, Severidad, Prioridad, Pasos para Reproducir, Resultado Esperado vs. Obtenido.
